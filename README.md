## Project overview

TripMate is a focused travel-planning concept that helps a traveler discover a sightseeing place, check that it is the intended place, save it to a trip shortlist, and find it again later.

The project deliberately explores one complete user task rather than attempting to design a full travel-booking service. Booking, payments, accommodation, transport, and route navigation are outside the current scope.

## Main user flow

1. Search for sightseeing places for the current trip.
2. Review a result and check its name and locality.
3. Save the selected place to the intended trip.
4. Receive a clear save confirmation.
5. Open the shortlist and retrieve the saved place.

The Figma file includes desktop and mobile wireframes, the main task flow, no-results and save-error states, usability-test documentation, iteration notes, and a mini UI guideline.

## Usability test — recorded evidence and limitations

Three anonymous university students tried the available click-through independently. They named Rome, Romania, and Vienna as their destinations. All three reached the saved-place shortlist without facilitator help (3/3).

One participant gave positive overall feedback, describing the prototype as enjoyable and easy to understand. This is a paraphrase, not a verbatim quotation. No separate verbal comment was recorded for the other two participants.

**Important limitations:**
- Search results are fixed sample content; the prototype does not perform live or destination-specific place search.
- The trial therefore tested completion of the available click-through, not live search for Rome, Romania, or Vienna.
- Detailed click paths, task time, pauses, errors, and confidence ratings were not recorded.
- The notes do not establish that a formal consent briefing was documented at the time. Any follow-up test should use the consent briefing in the Figma file and record consent accurately.

These results are an early formative signal from a very small, non-representative sample. They should not be treated as proof that the design works for all travelers.
