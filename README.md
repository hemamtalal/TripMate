## Project Overview

TripMate is a travel-planning concept explored through the UX/UI design process. The project focuses on helping users understand and organize the steps involved in planning a trip through a clear and approachable interface.

This repository is the central submission hub for the project. The homework deliverables are grouped in sequence so the development of the project can be followed from the initial problem exploration to the prototype and final presentation.

## Usability Testing

Initial prototype feedback was collected from three participants using different destination choices:

- Rome
- Romania
- Vienna

One participant described the prototype as enjoyable and easy to use, and said it was easy to understand how to find what they wanted. Participants explored their selected destinations independently.
