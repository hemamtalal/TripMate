# Homework 04 — Problem Definition and Opportunity Search

## Objective
Use the earlier research and competitor audit to define a focused, testable problem and identify possible solution directions.

## What I did
- Prepared a project brief defining the target user, primary task, organizational goal, constraints, success criterion, and exclusions.
- Created a stakeholder table and a user story for the sightseeing-shortlist task.
- Wrote a problem statement and three “How might we…?” questions.
- Generated solution ideas for place identification, trip-specific saving and retrieval, and accessible interaction.
- Compared ideas using an impact-and-feasibility prioritization matrix.
- Selected a focused direction: search for a sightseeing place, verify it, save it to a trip shortlist, and find it again.

## Deliverable
The project brief, stakeholder table, user story, problem statement, HMW questions, solution ideas, and prioritization are documented in the shared FigJam board.

## Evidence boundary
The chosen direction is a project decision informed by one participant account and the desk audit. The broader problem and proposed features still require validation with more travelers.
