# Homework 05 — Information Architecture and User Flow

## Objective
Organize the selected TripMate task into a clear content structure, navigation hierarchy, and step-by-step user flow.

## What I did
- Created a prioritized content inventory for trip context, search, results, place details, save destination, confirmation, shortlist, and recovery states.
- Defined a sitemap showing the relationship between the current trip, place search, details, save confirmation, and the saved shortlist.
- Listed the main screens and their functions.
- Mapped the main user flow from searching for a place through saving and retrieving it.
- Identified exceptional states including no results, ambiguous place identity, save failure, already-saved places, and an empty shortlist.
- Reviewed proposed interface labels and documented consistent wording such as “Search places,” “Save to trip,” “Your shortlist,” and “View shortlist.”
