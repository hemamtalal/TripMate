# Homework 06 — Low-Fidelity Wireframes

## Objective
Translate the selected information architecture and user flow into low-fidelity screen layouts for the core TripMate task.

## What I did
- Created desktop and mobile wireframes for the place-search experience.
- Designed the main screens for search/results, place details, choosing the trip destination, save confirmation, and shortlist retrieval.
- Kept the place name and locality visible so users can check which place they are saving.
- Included navigation and design notes to explain the intended purpose of each screen.

## Deliverable
The low-fidelity wireframes are in the shared TripMate Figma design file.

[Open Homework 6 — wireframes](https://www.figma.com/design/4zkXgJJRMEAR3MY3l41qCj/Prototipe?node-id=2-2)
