# Homework 07 — First Clickable Prototype and Informal Feedback

## Objective
Turn the wireframe flow into a clickable prototype and collect initial informal feedback on whether the main task is understandable.

## What I did
- Connected the main TripMate screens into a click-through journey.
- Represented the sequence of searching, inspecting a place, saving it to a trip, receiving confirmation, and opening the shortlist.
- Recorded first-trial notes and informal feedback about the prototype's ease of use and clarity.

## Deliverable
The clickable prototype and first-trial notes are included in the shared TripMate Figma design file.

[Open Homework 7 — clickable prototype and notes](https://www.figma.com/design/4zkXgJJRMEAR3MY3l41qCj/Prototipe?node-id=2-2)

## Scope
This is an interactive visual prototype. It does not implement live place search, real map data, or persistent application storage.
