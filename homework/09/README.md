# Homework 09 — Iteration, Components and Mini Design System

## Objective
Document evidence-informed prototype refinements and establish a small, consistent design system and handoff specification for the core TripMate flow.

## What I did
- Recorded three design iterations: making place identity clear before saving, giving explicit save confirmation and a next step, and improving search/save recovery.
- Documented the evidence, design hypothesis, change, rejected alternative, trade-off, expected effect, and remaining question for each iteration.
- Checked the main navigation path and the no-results and save-failed paths in a functional walkthrough.
- Defined reusable button, input-field, and place-card components and their variants/states.
- Documented spacing, typography, color variables, focus visibility, contrast, and accessibility rules.
- Prepared a developer handoff specification for the place-details screen, including content order, behavior, error/success states, keyboard use, and accessibility.

## Deliverable
The iteration log, modification check, mini design system, component showcase, and handoff specification are in the shared TripMate Figma design file.

[Open Homework 9 — iteration and design system](https://www.figma.com/design/4zkXgJJRMEAR3MY3l41qCj/Prototipe?node-id=2-2)

## Validation limitation
The three navigation paths were checked by the project owner; this is a functional walkthrough, not an independent participant usability test. Search results remain fixed sample content, and saving is simulated rather than persistent application functionality.
