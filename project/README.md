# TripMate — Individual UX/UI Project

TripMate is a focused travel-planning concept for travelers who want to discover a sightseeing place, verify its identity, save it to a trip shortlist, and retrieve it later.

The problem explored is the gap between discovering a possible place and being able to return to that choice while preparing a trip. The current result is a UX/UI prototype and supporting research documentation, not a coded or deployable travel application.
