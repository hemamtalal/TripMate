# TripMate — Individual UX/UI Project

## Project overview

TripMate is a travel-planning concept focused on one clear task: helping a traveler find a sightseeing place, check that it is the intended place, save it to a trip shortlist, and find it again later.

The project investigates the experience around collecting places while preparing a trip. It does not attempt to cover the whole travel process (transport, accommodation, bookings, payments, or itinerary automation).

## Problem

When people discover places while researching a destination, they need a clear way to verify which place they mean, connect it to the intended trip, and return to it later. TripMate explores a focused shortlist flow for this task.

This problem framing is exploratory. The research completed so far is small-scale and should not be treated as representative of all travelers.

## Target users

Travelers who research sightseeing options before or during a trip and want to collect places in one organized shortlist. The initial exploration used a provisional persona and a small amount of exploratory user input; this is not a validated user segment.

## Project goal

Design and evaluate a clear, accessible first version of the following user flow:

1. Search for a sightseeing place.
2. Inspect its name and location to verify its identity.
3. Choose the trip to which it belongs.
4. Receive clear save confirmation.
5. Reopen the trip shortlist and find the saved place.

## Scope

**Included**
- Problem exploration and early user research
- User journey, problem definition, and information architecture
- Desktop and mobile wireframes
- Click-through prototype for the main task
- Formative usability feedback and documented design iterations
- Mini UI guideline, reusable components, and handoff notes

**Not included in the current version**
- Live place-search API or map service
- User accounts or authentication
- Backend, database, or persistent cloud storage
- Booking, payment, accommodation, or transport features
- Production deployment

## Evidence and limitations

- Three university students independently completed the available click-through task (3/3).
- The destinations named during the sessions were Rome, Romania, and Vienna.
- One participant gave positive overall feedback, describing the prototype as enjoyable and easy to understand; separate feedback from the other two was not recorded.
- The prototype uses fixed sample content; it does not return live results for the named destinations.
- Detailed task times, click paths, errors, pauses, and confidence ratings were not collected.
- The three-person label-comprehension check identified in Homework 5 remains outstanding.
- See [project evidence and limitations](docs/project-evidence.md) for the evidence record.
